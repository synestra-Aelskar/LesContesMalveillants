# Ceinture porte-outils

`ceinture.png` est la source transparente créée avec l'outil intégré ImageGen.
`python Outils/ceinture_blp.py` produit le fichier BLP2/DXT5 utilisé par l'addon :
`LesContesMalveillants/ressources/ceinture/ceinture.blp` (1024 × 512).

Prompt final : « Ceinture porte-outils de fantasy vue de face, cuir brun usé,
boucle en laiton, plusieurs attaches et holsters vides, discrets motifs
d'éclairs évoquant la technologie du Val'Razkah, sujet isolé sur fond
transparent, silhouette lisible pour une interface de jeu, sans personnage,
texte ou décor. »
